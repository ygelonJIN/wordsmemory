9.3.x TreePage 词汇行格式规范

TreePage 中词根详情页的词汇列表采用独立行布局，每个词汇独占一行：

每行格式：
  {单词}={词根组合形式}={组合含义}={最终中文释义}//

示例：
  reassure=re+assure=再次使确信=使安心//
  recollect=re+collect=重新收集=回忆起//
  reconcile=re+concile=重新协调=和解//
  reproduce=re+produce=重新生产=繁殖//
  request=re+quest=一再寻求=请求//
  recommend=re+commend=再次赞赏=推荐//
  ...（以此类推）

点击行为：
  - 点击整行任意区域，跳转 RandomLearnPage 展示该单词完整学习界面
  - 该跳转行为不计入用户学习总进度（不写 Review_Log）
  - 仅更新 Card.Tree_Visit=1

样式规则：
  - 默认状态：FontWeight.w500，颜色 #000000，无下划线
  - 点击/选中状态：FontWeight.w700，颜色 #0000FF，TextDecoration.underline
  - 行高：2.5（lineHeight: 2.5）
  - 字号：16.0
  - 字体：GoogleFonts.inter

数据结构来源：
  - 词汇数据来源：Tree_Word 表 + Note 表（通过 Concept_UUID 关联）
  - 显示字段：Compound_Form + Final_Meaning
  - 每个词汇行绑定对应的 Concept_UUID 用于跳转

9.4.x 收藏按钮状态样式

收藏按钮位于 RandomLearnPage 单词详情区（拼写+音标行右侧）：

| 状态   | 文字      | 字体粗细     | 颜色      | 下划线    |
|-------|----------|------------|----------|---------|
| 未收藏 | 收藏      | w600       | #000000  | 有       |
| 已收藏 | 已收藏     | w700       | #0000FF  | 有       |

切换逻辑：
  - 点击"收藏"→ Card.Favorite=1，文字变为"已收藏"，样式切换
  - 点击"已收藏"→ Card.Favorite=0，文字变为"收藏"，样式回退
  - 通过 Card.Favorite 字段判断当前状态，动态渲染

Content_JSON 字段数据结构（用于话题阅读 Article.Content_JSON）：

类型：JSON 数组
元素结构：[{"t": "文本片段", "c": 0/1, "u": "UUID或null"}]

字段说明：
  - t: 文本片段内容
  - c: 颜色状态标记 (0=普通文本, 1=命中词汇)
  - u: Concept_UUID（仅 c=1 时有值，c=0 时为 null）

完整示例：
[
  {"t": "The ", "c": 0, "u": null},
  {"t": "evolution", "c": 1, "u": "uuid-001"},
  {"t": " of communication ", "c": 0, "u": null},
  {"t": "technology", "c": 1, "u": "uuid-002"},
  {"t": " vividly illustrates humanity's ", "c": 0, "u": null},
  {"t": "relentless", "c": 1, "u": "uuid-003"},
  {"t": " pursuit of efficiency. Initially, early inventors relied on a rather crude ", "c": 0, "u": null},
  {"t": "device", "c": 1, "u": "uuid-004"},
  {"t": "...", "c": 0, "u": null}
]

命中词汇渲染规则（见 9.3 节）：
  - c=1 的片段：FontWeight.w700，颜色 #0000FF，TextDecoration.underline
  - c=0 的片段：FontWeight.w500，颜色 #000000，无下划线
  - 点击 c=1 的片段：跳转 RandomLearnPage（不计入进度，更新 Card.Topic_Read=1）

7.3 用户设置项 (User_Settings 表 Key 一览)

| 设置项         | Key                    | 值类型   | 默认值    | 可选值                              |
|-------------|------------------------|---------|---------|-----------------------------------|
| 用户昵称       | user_name              | String  | ''      | 任意非空字符串                        |
| 当前词书       | current_book           | String  | 'cet6'  | 'kaoyan2027' / 'cet6' / 'cet4'      |
| 单次学习数量     | single_session_limit   | String  | '70'    | '10' / '20' / '30' / '50' / '70' / '100' |
| 显示词根词缀     | show_etymology         | String  | '1'     | '1' (显示) / '0' (隐藏)              |
| 显示词义       | show_definition        | String  | '1'     | '1' (显示) / '0' (隐藏)              |
| 显示例句       | show_example           | String  | '1'     | '1' (显示) / '0' (隐藏)              |
| 每日刷新时间     | daily_refresh_hour     | String  | '0'     | '0' / '4' / '8' / '18'              |

存储位置：User_Settings 表（热数据库 Hot_DB）
读取接口：BackendManager.loadSettings() → SettingsData
保存接口：BackendManager.updateSetting(key, value)

样式选中状态：
  - 未选中：FontWeight.normal，颜色 #000000
  - 选中：FontWeight.w600，颜色 secondary (FlutterFlowTheme.of(context).secondary)
  - 下划线：两者均有 TextDecoration.underline
