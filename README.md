# WordMemory

基于 FSRS 间隔重复算法的词汇学习 App，支持语义阅读中词级高亮与一键学习。

## 核心功能

- 语义阅读：在英文文章中自动标注词库中的词汇（蓝色高亮 + 加粗 + 下划线），点击即可进入学习
- FSRS 学习引擎：科学的间隔重复算法，根据记忆状态自动安排复习
- 多维学习：复习模式、学习模式、快速筛选、收藏夹
- 结果报表：学习统计、评级分布、掌握程度追踪
- Android / iOS / Web 三端支持

## 技术栈

Flutter + sqflite + go_router + Google Fonts

```bash
flutter pub get
flutter run
```
